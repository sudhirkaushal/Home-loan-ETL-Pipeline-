# Home Loan ETL Pipeline | SQL | PySpark | AWS

> Converting raw home loan leads into high-quality leads for banks using ETL.

### 🔴 Problem I Solved in my job
As a Data Analyst in Home Loan DSA, I saw banks waste 40% time calling low-quality leads. Manual Excel work took 3 hours daily.

### ✅ My Solution - End to End ETL
**Bronze (S3)** -> Raw CSV leads
**Silver (PySpark)** -> Deduplication, Cibil Filter, City Cleaning
**Gold (Snowflake)** -> City-wise aggregation for Power BI Dashboard

### 🛠️ Tech Stack
- SQL (Window Functions, CTEs, Deduplication)
- Python, Pandas, PySpark
- AWS S3, Snowflake, Power BI
- Git, GitHub

### 📁 Project Structure
- /sql - SQL queries for cleaning
- /pyspark - Main ETL job
- /python - Pandas cleaning scripts

### 📈 Result
- Reporting time: 3 hrs -> 10 mins
- 40% low-quality leads filtered before calling
